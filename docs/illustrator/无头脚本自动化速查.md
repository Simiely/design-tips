# 无头脚本自动化速查（零弹窗跑通）

> 目标：**双击 / 一条命令**就让 Illustrator 跑一个 JSX 脚本，全程**不弹任何确认框**、**不用手点**。
> 本文是"怎么做到"的浓缩版；具体案例见 [svg还原分层AI.md](svg还原分层AI.md)。

## 一、零弹窗的三个必要条件（缺一不可）

| # | 条件 | 做法 | 漏了会怎样 |
|---|---|---|---|
| 1 | **外部脚本安全警告**（"是否允许运行脚本"） | `app.preferences.setBooleanPreference("ShowExternalJSXWarning", false)` | 首次弹一次授权框，点掉后记住选择即可；建议脚本开头自动设置该偏好（自我加固） |
| 2 | **脚本与 Illustrator 同盘** | 启动前把脚本复制到 **AI 所在盘**（`%SystemDrive%`，本机 `C:\ai\jobs\`），再用该路径启动 | 跨盘（D: vs C:）→ 弹**模态** "File not found"（路径还丢盘符）并**阻塞主线程**，不点掉脚本永不开始 |
| 3 | **不靠命令行传文件给"打开"逻辑** | 用 `-r` + 同盘路径，或 COM `DoJavaScriptFile` | 若走 Startup Scripts（AI 无参数启动）则天然满足，但本版本不触发（见下） |

> 条件 2 是最容易踩的：症状是"脚本好像没跑"，日志迟迟不出现，其实是弹窗把 AI 卡住了。

## 二、三条启动通道怎么选

| 通道 | 命令 | 弹窗 | 能确认执行成功 | 能等完成 | 需管理员 | 备注 |
|---|---|---|---|---|---|---|
| **A. `-r` + 同盘暂存**（默认首选） | `powershell -ExecutionPolicy Bypass -File run-ai-headless.ps1 -Jsx x.jsx -Log log.txt` | **零** | 只能看日志 | 不能 | 否 | 14–20s 跑完一个真实转换 |
| **B. COM `DoJavaScriptFile`** | `cscript //nologo run-ai-headless.vbs x.jsx log.txt 600` | 零 | **可以** | **可以** | 否 | 需要传参/等完成时用；需先 sleep 10s 等 AI 启动完 |
| **C. Startup Scripts 派发** | AI 无参数启动，脚本自取任务 | 零 | 靠日志 | 不需要等 | **是** | **本机 AI 2026 build 30 实测不触发**，仅留作其他版本备选 |

## 三、标准工作流（照做即可复用）

**第 1 步：写任务脚本**——直接复制 `scripts/illustrator/template-job.jsx`，改顶部配置区。
必备四件套：`#targetengine "session"`、全绝对路径、顶层 `try/catch` 写日志、结尾 `app.quit()`。

**第 2 步：跑**（通道 A，推荐）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\illustrator\run-ai-headless.ps1 `
    -Jsx "D:\work\my-job.jsx" -Log "D:\work\_ailog.txt" -TimeoutSec 540
```

启动器会：清旧实例 → 等进程真消失 → **把脚本复制到 `%SystemDrive%\ai\jobs\`** → 以该路径 `-r` 启动
→ 轮询日志到 `done` → 返回语义化退出码。**超时默认不杀 AI**（杀进程会腰斩脚本）。

**第 3 步：判读**——只看日志，不看有没有弹窗：

| 日志 | 结论 |
|---|---|
| 出现 `done` | 成功 |
| 出现 `ERROR:` | 脚本内部异常，按内容改 |
| 一直没出现、也没 ERROR | AI 可能正被弹窗卡住 → 看屏幕；或脚本还在跑（大文件）→ 加大 `-TimeoutSec` |
| 文件都没生成 | 脚本根本没启动 → 检查 `-Log` 路径与脚本内 `LOG` 是否一致、脚本路径是否存在 |

**第 4 步：验证产物**（双基准）——浏览器渲染 SVG 作参考 + AI 自身导出 PNG，两者做像素 diff；
再用 `verify-layers.jsx` dump 图层结构核对分组。

## 四、退出码对照

| 码 | 含义 | 动作 |
|---|---|---|
| 0 | 成功（日志含 `done`） | — |
| 2 | 参数/文件不存在 | 核对 `-Jsx` / `-Log` 路径 |
| 3 | 旧实例杀不掉 | 手动关掉 Illustrator 再跑 |
| 4 | 脚本内部 ERROR | 看日志最后几行 |
| 5 | 超时（AI 未被杀，可能还在跑） | 加大 `-TimeoutSec`；别急着杀进程 |
| 6 | 超时且指定了 `-KillOnTimeout` | 脚本已强杀，重查 |

## 五、排错速查（现象 → 原因 → 动作）

| 现象 | 原因 | 动作 |
|---|---|---|
| 弹 "File not found"，路径无盘符，**脚本不开始** | 脚本与 AI **跨盘** | 把脚本复制到 `%SystemDrive%` 再启动（启动器已内置） |
| 弹 "是否允许运行脚本" | 外部脚本安全警告 | 跑一次 `suppress-external-warning.jsx`；或让脚本开头自设偏好 |
| 点了弹窗但脚本仍不跑 | 弹窗点的是"取消"，或 AI 还在启动 | 确认日志是否有新行；必要时加长等待 |
| 日志停在中途、AI 界面卡住 | 大文件操作中（打开 SVG / 导出） | 等，别杀进程 |
| 脚本里 `$.fileName` 为空 | 外部启动的正常现象 | 一律用绝对路径，别从 `$.fileName` 推导 |
| `arguments[0]` 是 `[object BridgeTalk]` | 外部调用不转发位置参数 | 用配置区 / sidecar 文件 / 环境变量传参 |
| 图层配对全错 | `doc.groupItems` 含嵌套组且顺序≠文档顺序 | **按组名配对**，只遍历 `layer.pageItems` |
| 中文在 PowerShell 里变乱码 | 日志是 UTF-8，PS 5.1 按 ANSI 读 | `Get-Content -Encoding UTF8` |
| `.ps1` 报"字符串缺少终止符" | PS 5.1 读无 BOM 的 UTF-8 脚本按 ANSI 解析 | `.ps1`/`.vbs` 一律纯 ASCII |

## 六、脚本必备要素（模板已内置）

```jsx
#target illustrator
#targetengine "session"                                   // 多次调用间保留变量
try { app.preferences.setBooleanPreference("ShowExternalJSXWarning", false); } catch (e) {}  // 自我加固
app.userInteractionLevel = UserInteractionLevel.DONTDISPLAYALERTS;                          // 批处理免弹窗
// 顶层 try/catch + 写日志到绝对路径：既确认"真跑了"，也能捕获错误
// 结尾 app.quit()：让 AI 正常退出（偏好才会落盘）
```

## 七、本版本限制

- **Startup Scripts 不触发**：AI 2026 build 30 实测不执行安装目录 `Startup Scripts\` 里的 .jsx
  （安装成功、派发器未被执行、派发日志为空）。该路线仅作其他版本备选。
- **跨盘必弹窗**：只要脚本不在 AI 所在盘，就会触发模态报错并阻塞——这是本版本最硬的约束。
