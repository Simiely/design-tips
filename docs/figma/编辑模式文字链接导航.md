# 编辑模式：文字链接导航（最推荐）

## 场景
**不进原型、不加连线**，在普通编辑模式下，点导航文字就能跳到文件内某块画板 / 页面。适合自己整理大文档时"点一下跳到某块"，也适合交付一个带跳转目录的说明页。

## 原理
Figma 的「给文字加链接（Add links to text）」支持链接到**当前文件里的画板 / 页面**。官方原话：链接到"Page or frame in current file"时，点击会跳转到当前文件的那一页 / 画板。

## 做法（两步）

### 第 1 步：复制目标链接
- 目标画板：在画布**右键那块 Frame** → `Copy/Paste as` → **`Copy link`**。
- 目标页面：左侧图层面板**右键页面名** → **`Copy link to page`**。
- 浏览器方式：可复制选中对象对应的地址栏链接。

### 第 2 步：在导航文字上加链接
1. **双击**进入文字，选中要加链接的字。
2. 加链接（任选其一）：
   - 属性面板的 **`Create link`** 按钮；
   - 或快捷键 `Ctrl+Shift+U`（Windows）/ `⌘+Shift+U`（Mac）。
3. 粘贴第 1 步复制的链接，回车。

完成后：编辑模式下点这段带下划线的文字 → 跳到对应画板。给每个导航项重复一遍，即可做出文档内自由跳转的导航。

## 坑
- **只能给文字加**链接；图片 / 矢量在编辑模式加不了（想给图形加只能走原型连接）。
- 加了链接的文字**默认带下划线** → 可作为"是否生效"的判断。
- **必须双击进入文字、并且已选中字**，`Create link` 才会出现；单纯框选整个文本框没有按钮。
- 点击跳转前要**先退出文字编辑**（点空白 / 按 Esc），否则点的是把光标放进文字。
- 按住 `Ctrl/⌘` 点击会**阻止跳转**。
- 链接目标不可用浏览器地址栏 / 分享对话框里的"文件链接"，要用**画板级 Copy link**，否则跳不到位置。
- 入口位置因版本而异：可能在右侧属性面板，也可能在**选中文字后下方浮现的快捷按钮**里（图标：回形针 / 链条），还有可能在「···」更多里。认图标，别认死位置。

## FAQ
- Q：点击没反应？
  A：先退出文字编辑态再点；确认带下划线（链接生效）；松开 Ctrl/⌘。
- Q：找不到 Create link？
  A：双击进入文字并选中字；入口在下方浮动按钮（回形针图标）或「···」里；属性面板在右侧还是下方因版本而异。
