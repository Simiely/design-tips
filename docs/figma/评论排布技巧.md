# 评论排布：避免评论簇/合并

## 场景
文件里评论一多，Figma 会把**贴得很近的评论自动叠加成一个"评论簇（cluster）"**，显示一个带数字角标的堆叠小图标，很难看清是几条、谁发的。

## 做法
1. **展开簇**：鼠标悬停在堆叠角标上 → 可见数量与作者；**点击簇** → 聚焦并展开全部评论。
2. **拆开已叠的**：选中评论 → 按住画布上它的**评论别针（pin）**→ 拖到新位置松开。
3. **主动错位摆放（最有效的预防）**：把评论别针放到元素之间的**留白处**，并且**彼此错开、间距拉开** —— 位置一分散，Figma 就不会把它们合并成簇了。
4. **钉到具体图层**：把评论钉在某个 **Frame / 图层**上（而非自由坐标），评论会跟随该元素，比自由坐标更稳定、不易乱堆。

## 坑
- Figma **没有"关闭自动堆叠"的原生开关**，只能靠手动摆放位置来规避。
- 元素太挤时，别针拖过去也很容易再次吸拢；**放大视图（`+`）留出空白**再放更稳妥。
- 别针拖到元素正上方时会被**吸附回该元素**，放到留白处更稳定。
