# 导航速查（完整汇总）

Figma 文档内导航/跳转的完整笔记，**只收录实际用到并验证过**的做法。

## 0. 最核心的结论

想在**普通编辑模式**里"点一下就跳到文档内某块内容"，正解是 **给文字加链接（Add links to text）** 指向本文件的画板/页面 —— 不用进原型、不用加连线。

> 未经验证的其它路径（原型连线跳转、板内 Overlay/Scroll To、连线隐藏治理、Create component 与链接的界面区分等）暂不入库，后续在真实环境验证后再补。

## 1. 编辑模式：文字链接导航（最推荐）

**场景**：不进原型、不加连线，在普通编辑模式下，点导航文字就跳到文件内某块画板 / 页面。适合整理大文档时"点一下跳到某块"，或交付一份带跳转目录的说明页。

**原理**：Figma「给文字加链接」支持链接到当前文件里的画板/页面。链接到"Page or frame in current file"时，点击会跳转到当前文件的那一页 / 画板。

**做法（两步）**：

第 1 步：复制目标链接
- 目标画板：画布上**右键那块 Frame** → `Copy/Paste as` → **`Copy link`**。
- 目标页面：左栏图层面板**右键页面名** → **`Copy link to page`**。

第 2 步：在导航文字上加链接
1. **双击**进入文字，选中要加的字。
2. 加链接（任选其一）：属性面板 **`Create link`**，或快捷键 `Ctrl+Shift+U`（Win）/ `⌘+Shift+U`（Mac）。
3. 粘贴第 1 步复制的链接，回车。

完成后：编辑模式下点这段文字 → 跳到对应画板；每个导航项重复一遍即可构成导航。

**坑**：
- 只能给**文字**加链接（图片/矢量编辑模式加不了）。
- 加了链接的文字默认**带下划线**，可作为是否生效的判断。
- 必须**双击进入文字并选中字**，`Create link` 才会出现（单纯框选整个文本框没有）。
- 点击跳转前要**先退出文字编辑**（点空白/Esc），否则点的是放光标。
- 按住 `Ctrl/⌘` 点击会阻止跳转。
- 链接要用「右键画板 → Copy link」的**画板级链接**，别用地址栏/分享文件链接。
- 入口位置因版本而异：可能在右侧属性面板，也可能在**选中文字后下方浮现的快捷按钮**里（回形针/链条图标），还可能在「···」更多里 —— 认图标，别认死位置。

**FAQ**：
- Q：点击没反应？ A：先退出文字编辑态再点；确认带下划线；松开 Ctrl/⌘。
- Q：找不到 Create link？ A：双击进文字并选中字；入口在下方浮动按钮（回形针）或「···」；面板位置随版本变。

## 2. 编辑模式：快速定位

**场景**：编辑画布时快速"跳到文档里某块内容"，方便查看、改稿、对版。

**做法**：
1. **`Ctrl+/`（Mac `⌘/`）**：弹出搜索 → 输图层/画板名 → 回车直达。文档再大也随便跳，最推荐。
2. **左栏 Layers**：点任意图层/画板名，视图自动跳过去；双击名字直接选中该块。
3. **Section 做目录**：把相关画板归组命名，左栏变可折叠分区标题，点名即跳到该组。
4. **`Shift+2`**：缩放视图框住当前选中对象，配合跳转查看细部。

**坑**：这是"自己挪视角"，不会产生观众可点的交互；要"作品里观众能点跳"需另走（如文字链接导航）。
