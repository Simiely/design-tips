# 编辑模式：快速定位

## 场景
想在编辑画布时快速"跳到文档里某块内容"，方便自己查看、改稿、对版。

## 做法
1. **`Ctrl+/`（Mac `⌘/`）快速菜单** —— 弹出搜索后输入图层 / 画板名字 → 回车直接跳到那儿。文档再大也随便跳，是最推荐的方式。
2. **左栏 Layers（图层）面板** —— 每块画板 / 内容都带名字列在左侧，**点名字**视图就自动跳过去并选中；双击名字直接选中该块。
3. **Section（分区）做目录** —— 把相关画板归成一块并命名，左栏变成可折叠分区标题，点击分区名 = 跳到那一组，适合"导航栏 + 多块内容"结构。
4. **`Shift+2`** —— 缩放视图到正好框住当前选中对象，配合跳转查看细部。

## 坑
- 这是"**自己挪视角**"，不会产生观众可点击的交互；要"作品里的观众能点跳"必须走原型。
- 想做出"编辑模式下点画布内元素就跳"，用主题3的文字链接导航。
